# 90-Day Learning Plan

## Goal

Improve my practical AI skills and make my work more visible and easier to share with others.

## My Plan

### 1. Habit

**Weekly written update**

Every Friday, I will write a short update about:

* What I worked on
* What I learned
* Any problems or risks
* What I will do next

**Time:** Friday afternoon
**Duration:** 10-15 minutes

### 2. Capability

**Build and verify a small AI/LLM feature**

Over the next 90 days, I want to build a small project using an LLM API and create a simple evaluation set to verify the results.

I will consider this completed when:

* The feature is working
* I have at least 20 test cases
* I have documented the expected results and failures

**Time:** 2 hours per week

### 3. Artifact

**AI Evaluation Example**

I will create a small repository containing:

* The example application
* The evaluation cases
* Basic documentation
* Notes about failures and lessons learned

The goal is to have something that another engineer can read, run and understand.

## Monthly Checkpoint

At the beginning of each month I will review:

* Am I keeping the weekly habit?
* Am I making progress on the AI project?
* Is the scope still realistic?
* What should I reduce or change if I am falling behind?

## Success Criteria

At the end of 90 days I should have:

* A consistent weekly learning habit
* A working AI/LLM example
* A real evaluation set
* A public artifact that I can share with others
