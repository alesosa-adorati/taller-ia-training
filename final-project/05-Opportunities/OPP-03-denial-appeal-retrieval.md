# OPP-03 — Prior Appeal Retrieval and Evidence Assist

## Source workflow

WF-R3 — Denial appeal preparation.

## Workflow change

Given a denial category, retrieve relevant prior successful appeals and supporting documents, summarize similarities and present evidence to a billing specialist. The system does not autonomously submit an appeal.

## Impact

**Measured — B9:** 3,100 denials worked/month.

**Measured — B9:** 58% of appeals are overturned.

**Measured — B7:** The appeal folder contains approximately 1,400 documents.

No representative retrieval or drafting time baseline exists beyond one reported appeal example.

## Suitability

| Flag | Assessment | Reason |
|---|---|---|
| Repetitive | Yes | Searching prior letters/documents |
| Data available | Partial | Large folder exists but lacks indexing |
| Human judgment separable | Yes | Specialist retains final decision |
| Measurable | Yes | Retrieval time and reuse can be tested |
| Governance feasible | Conditional | PHI and payer data require controls |

## Evidence

**Reported — B8:** Nia wants the system to find the three best prior appeals rather than write the appeal.

**Reported — B3:** One appeal example took approximately 40+ minutes for letter and documents.

## Verdict

**AUGMENT / DISCOVERY PILOT**.
